# Employee Data Management System Using MySQL

## Project Overview

The Employee Data Management System is a beginner-level SQL project
developed using MySQL.

The project manages employee and department information and
demonstrates SQL operations used to store, retrieve, update,
delete, and analyse employee records.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Database Details

Database Name: employee_management_db

### Tables

1. Employees
2. Departments

### Employees Table Columns

- Employee_ID
- Employee_Name
- Department_ID
- Salary
- Joining_Date
- City

### Departments Table Columns

- Department_ID
- Department_Name

## Project Files

1. 01_Create_Database.sql
   - Creates the database and tables.

2. 02_Insert_Data.sql
   - Inserts department and employee records.

3. 03_Select_Queries.sql
   - Retrieves employee information.

4. 04_Filter_Sort.sql
   - Filters and sorts employee records.

5. 05_Aggregate_Queries.sql
   - Performs employee and salary analysis.

6. 06_Update_Delete.sql
   - Updates and deletes employee records.

## Key Operations

- Created a relational employee database.
- Stored employee and department information.
- Retrieved employee records using SELECT queries.
- Filtered employees based on salary, department, and city.
- Sorted employees by salary and joining date.
- Calculated total and average salaries.
- Analysed department-wise employee counts.
- Updated and deleted employee records.

## Project Objective

The objective of this project is to understand relational
database management and practise SQL queries for employee
data management and basic data analysis.
